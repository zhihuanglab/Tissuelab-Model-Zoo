# Linux GPU: CUDA 12 via tensorflow[and-cuda]. macOS/Windows: CPU wheel.
#
# GPU acceleration for TensorFlow is NOT supported on Windows. This is not a
# packaging choice -- there is no combination of versions that enables it:
#   - The Windows wheel is built without CUDA, so it has no GPU kernels at all
#     (tf.sysconfig.get_build_info()["is_cuda_build"] is False since TF 2.11).
#     TensorFlow prints this warning itself at import time.
#   - The and-cuda extra needs nvidia-nccl-cu12, which NVIDIA does not publish
#     for Windows, so pip cannot even resolve it there.
#   - TF 2.10 was the last Windows-GPU release and ships no cp311 wheel, so it
#     is unreachable on Python 3.11 (it also needs numpy 1.x, protobuf <3.20).
# Scope: only the StarDist forward pass runs on CPU. torch/torchvision below
# still use CUDA 12.6, so every other GPU path in this node is unaffected.

tensorflow[and-cuda]==2.21.0; sys_platform == "linux"
